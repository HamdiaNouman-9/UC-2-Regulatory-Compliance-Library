# CHG-006 hidden text removed before analysis: handoff (2026-11-04)

Branch `feature/chg-006-hidden-text-removal`, from `main`. Built, measured
against the restored database copy and 22 PDFs, unit tested, verified
through the real gate on every stored page, and run once end to end for one
regulator. Design, measurements and decisions are in
[chg_006_hidden_text_removal.md](chg_006_hidden_text_removal.md).

## What the branch does

Before text reaches the requirement and activity analysers, the parts a
reader cannot see are removed from the model's copy: on pages, elements
hidden by `display:none`, `visibility:hidden`, `hidden`, `aria-hidden`,
zero size, zero font, off-screen placement or collapsing clip; in PDFs,
spans under four points, outside the page box, or in the colour of what is
drawn under them. What was removed, why, and a few samples are written to
`extra_meta["hidden_text"]` on the row. The stored HTML, the files, the
content hash and `updated_at` are not touched.

What is deliberately kept: sections a reader can click open, `<details>`,
white text on a dark bar, captions over images, OCR layers on scanned pages,
and ghost copies that duplicate visible text (reported as duplicates).

## Running it

```
.venv/Scripts/python.exe -m pytest tests/test_hidden_text.py tests/test_hidden_text_gate.py tests/test_hidden_text_recording.py
python -m scripts.hidden_text_scan                 # stored pages, read-only
python -m scripts.hidden_text_scan --pdf-dir DIR   # files
```

The scan is the tool for a new regulator: run it before trusting the rules
on a CMS the allowlist has never seen, and read the reason ranking.

## For CHG-008 (quarantine)

The counts are in `extra_meta["hidden_text"]["page"]["removed_chars"]`,
`["kept_chars"]` and `["files"][i]["removed_chars"]`. The measurement shows
a ratio alone is not a safe trigger: 15 genuine rows are tiny landing pages
where one hidden label is most of the page. Require a minimum absolute size
as well as the ratio.

## Not on this branch

- Stylesheets are not evaluated for pages; only inline hiding is seen. A
  class-hidden element is treated as openable by the reader.
- Office files (`.docx`, `.xlsx`) go through `office_text_extractor` and
  are not inspected for hidden text.
- The hidden-text counts are not shown in the review UI yet; they are in
  the row's `extra_meta` and in the processing log.
