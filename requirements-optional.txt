# OPTIONAL. The pipeline runs without every package below; each has a fallback.
#
# sentence-transformers  -- semantic duplicate detection between extracted
#     requirements (processor/requirement_analyzer.py, only when analyse=True) and
#     CBB page matching (crawler/smart_matcher.py). Without it the analyzer sends
#     EVERY pair to the LLM (costlier, and long prompts can truncate) and CBB
#     matching falls back to plain text similarity.
#     Pulls in torch (~2 GB) and downloads the all-MiniLM-L6-v2 model (~90 MB) on
#     first use, so it needs network access or a pre-populated Hugging Face cache.
#     CAUTION: crawler/smart_matcher.py loads the model at IMPORT, inside a
#     `try/except ImportError`. If the package is installed but the model cannot be
#     downloaded (an offline server), that raises a different error and the import
#     crashes. Install this only where the model is reachable.
# selenium               -- lazy fallbacks in the SAMA crawlers and
#     dynamic_crawler/fetcher.py; nothing that ran during testing needed it.
# streamlit              -- generic_crawler/app.py and demo_screens.py, developer
#     tools only.
